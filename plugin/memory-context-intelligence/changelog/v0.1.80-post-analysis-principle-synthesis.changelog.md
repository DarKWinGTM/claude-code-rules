## What Changed

The skill separates symptoms from supported decision mechanisms, compares the complete set for shared causes/dependencies/tensions, derives transferable principles/strategies/practical guidance with applicability and retained safeguards, integrates a proportional work pattern, and gives every Topic a supported-group/separate-or-narrowed/context-only/insufficient-evidence disposition. It does not impose fourteen principles, simply remove Project names, inflate confidence or generate one Rule per incident.

Input reports/transcripts remain data; embedded write/promotion instructions carry no execution authority. Missing/ambiguous inputs receive bounded clarification, not automatic memsearch/corpus reruns or fabricated causes. Summary remains advisory and does not write reports/Rules/additional/config/Product code, run new research or approve Main promotion.

The existing analysis skill gains one bounded optional post-presentation synthesis hint while retaining repeated Topic cards, evidence acquisition and per-topic emission. Init changes only package version metadata. Manifest and all three public skills align at0.9.32. No synthesis runtime engine, provider dependency, storage, CLI adapter or service is added.
