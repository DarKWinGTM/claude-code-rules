## What changed

This wave approves and plans the source implementation for deterministic post-presentation selected-topic handling. The initial `/memory-context-intelligence:analysis` response remains read-only and advisory. After the user explicitly selects one or several topics and asks to proceed, the target workflow creates one rich standalone trial artifact per topic under the selected `additional/memory-context-intelligence/` namespace.

The implementation target includes:
- explicit separation of `selected_for_additional_trial=True` from `main_rules_promotion_approved=False`
- candidate entailment and semantic evidence normalization before emission
- standalone artifact bodies with no dependency on temporary memory shards, transcripts, packet paths, absolute analysis-only paths, or raw `path:line` anchors
- full selected-set destination preflight before the first write
- fail-closed collision handling that preserves every existing byte
- no active overwrite path in the deterministic selected-topic workflow
- path, namespace, traversal, and symlink containment under the selected additional-stage root
- independent one-topic packet/artifact handling for multi-topic selections

## Boundaries kept

- `/memory-context-intelligence:analysis` remains the initial read-only review surface

- `trace_evidence` remains the live pattern anchor
- `recall_evidence`, `durable_memory_context`, and `governance_context` remain supporting evidence classes
- selected additional-stage creation does not approve Main RULES promotion
- Phases 017-018 remain deferred and unchanged

- publication, marketplace mutation, installation mutation, and stable/broad production readiness are not claimed
