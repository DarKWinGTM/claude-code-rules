## Changed

The analysis Skill now interprets a natural-language request before calling preparation. Topic count, subject, language, detail and depth remain caller-context instructions; only genuinely requested evidence restrictions/config/mode reach existing runtime interfaces. Without those controls, explicit empty arguments preserve configured incremental defaults. Real literal filters and day/session/lookback/catch-up requests remain available; material ambiguity is clarified before acquisition. No phrase-whitelist parser, config field, progress schema or new runtime owner is added.

The observed0.9.40 invocation `Minimium Rules 5 topic` incorrectly became a literal scope filter, returned zero canonical excerpts and did not enter progressive analysis. That result demonstrated argument misrouting, not corpus-wide absence of useful topics. The correction preserves eligibility, no-filler output, bounded acquisition and semantic completion; a requested minimum alone does not authorize extra batches or catch-up.
