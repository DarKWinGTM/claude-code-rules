## Changed

Normal analysis resumes the oldest unprocessed history instead of repeatedly sampling a recent window. Day/record/character/byte caps bound each batch rather than history age. Complete contiguous prefixes progress within a day; same-day/backdated appends remain discoverable. Explicit `mode=catch-up` follows sequential caller analysis/acknowledgement through one invocation endpoint, excluding later appended input.

A separate MCI progress store records pending/completed bindings, per-source prefix cursors/hashes and opaque keys. Preparation never advances semantic progress. Caller `analyzed` or successful `no-topics` acknowledges exactly one matching complete batch; failed/interrupted/unacknowledged, stale/corrupt state and source rewrite do not skip work. Duplicate completion is idempotent; expected-version/native lock/atomic replace protect updates. No raw traces/transcripts or topic ledger is persisted.

Startup now discovers availability without acquiring evidence/state, then the caller safely passes slash arguments before preparation. This follows official Skills argument-text semantics rather than assuming shell environment export, and avoids untrusted text in eager command injection. Corpus/Memsearch/governance stay read-only; only MCI pending/completed progress is written. Explicit narrow/supplemental inspection and direct intake/replay/trial remain stateless. Strict eligibility, novelty, privacy and additional/Main approval boundaries remain.
