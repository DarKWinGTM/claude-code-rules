## What Changed

The analysis payload now exposes `topic_discovery_evidence`, a capped trace-only projection derived from the existing signals report. It carries actual excerpts with run-local references, omitting transcript paths, session IDs, and context-only records. This gives the caller-session skill bounded evidence to share with independent read-only discovery lenses without another intake or corpus query.

The analysis skill distinguishes optional parallel candidate discovery from Phase 012's deterministic in-process lanes and Phase 069's post-eligibility deepening. When multiple evidence axes and the caller can keep worker tasks bounded to the excerpts, the caller may launch Developer/process, Security, and Architect perspectives concurrently. The main session verifies references, combines suggestions with local candidates, and applies the unchanged Phase 075 eligibility gate—including semantic deduplication—before deepening or presentation. Agent Teams are conditional and no runtime setting is changed.
