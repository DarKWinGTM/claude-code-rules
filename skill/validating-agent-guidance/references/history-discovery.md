# Discover Reusable Guidance from Work History

Use bounded history evidence to identify transferable procedures, not to manufacture failures or meet a topic quota.

1. Define the selected source scope, factual question and permitted actions. Use existing history/recall mechanisms if available; their output is a lead, not current truth. Choose input-byte, record-size and retained-output bounds before parsing large records, and report partial coverage.
2. Preserve speaker and provenance. Separate user-authored direction, observed action/result, assistant proposal, peer relay and generated summary. A concern, request or correctly handled precaution does not establish a previous defect.
3. Extract the supported mechanism and its applicability. Distinguish direct observations from explanatory inference. Multiple summaries of one event are not independent incidents, and a later source label does not establish the original author or intent.
4. Keep lesson origin separate from disposition: accepted, rejected, deferred and unresolved proposals remain distinct. Repeated assistant wording cannot become user approval. Preserve selected outcomes and constraints when later corrections retire an earlier frame.
5. Compare against current applicable instructions and existing Skills. Enrich the fitting procedure for a distinct reusable lesson; avoid near-duplicate owners, project-only policy and one-off narratives. Revalidate remembered patterns against the actual current context.
6. Require the candidate title, claimed problem and proposed change to follow from the bound evidence. Narrow a supported lesson when the trace is narrower; demote context-only material or reject unrelated candidates. Fewer or no candidates is a valid outcome.
7. Report each qualifying candidate in the requested format with transferable procedure, source/evidence strength, scope and limits, existing owner fit and disposition. Do not expose private transcripts or local paths in reusable copy, stage changes or create tasks merely because a candidate exists.

If a named tool or channel is unavailable, state that boundary and use only an authorized substitute. A history-based proposal is not an implemented instruction, independently verified recurrence or measured improvement.
